# Предприятия космонавтики · карточки только для админки

Добавлены 21 карточка третьего уровня: РКК «Энергия», РКЦ «Прогресс», ЦПК, ЦЭНКИ, Роскосмос, НПО Лавочкина, НПО Энергомаш, МАК «Вымпел», ММЗ «Вымпел», ОКБ «Факел», НПО «Молния», Центр Хруничева, АО «РЕШЕТНЁВ», НПЦАП, РКС, НПО автоматики, КБХА, КБОМ, ВНИИРА, ЛИИ и ЦАГИ.

Каждая карточка содержит направления деятельности, значимые проекты с указанием стадии, историю, прошлые программы, источники и тематические переходы. 59 источников, 132 связи; обратные кнопки добавлены к 33 контекстам площадок, ракет, моделей и сценариев. Роль участника подписана отдельно от текущего оператора площадки. Одноимённые предприятия «Вымпел» и посадочный комплекс ВНИИРА разделены. Преемственность ВНИИРА после объединения 2025 года отражена; непроверенный текущий портфель ММЗ не выдуман.

Изменены ровно четыре runtime-файла: workshop.html (один динамический импорт), src/admin-organizations.js, src/admin-organizations-index.js, data/admin-organizations.json. Публичные index.html, museum.html, энциклопедия, существующие модели и сценарии не изменены. Полные статьи загружаются при первом открытии; дополнительных циклов отрисовки и 3D-ресурсов нет. Админка является существующей статической мастерской: это ограничение отображения, не новая система авторизации.

## Точный исходный артефакт

Рабочий сайт использует более новую серверную сборку, чем runtime в GitHub main. Поэтому здесь сохранён проверенный **изолированный патч к фактической серверной базе**, без замены старого main файлами других задач. `source.patch.gz` содержит полный текст трёх новых файлов и точное добавление в workshop.html. Развернуть его можно только поверх `baseRelease` из manifest.json после проверки исходных SHA-256; итоговые SHA также зафиксированы в манифесте. Это архив исходников опубликованного изменения, а не перенос остальных серверных изменений в main.

## Проверки

Результаты браузерных сценариев и публикации находятся в delivery-report.json. Проверяются все 21 карточка, поиск, обратные кнопки, переходы к событиям/моделям/площадкам, один запрос полного корпуса, прямая ссылка, отсутствие раздела и его запросов в публичном музее. Статическая проверка сверяет ссылки с настоящими каталогами и синтаксис модулей/встроенных скриптов. Публичные SHA-256 подтверждают точные файлы и сохранение 12 контрольных файлов.

Первые проверки обнаружили перекрытие панелью инструментов; исправлена её совместная работа со справочником. Отдельный мобильный прогон ошибочно искал дополнительные ссылки в свёрнутой панели сценария: тест исправлен на реальное нажатие «Подробнее». Отчёты этих прогонов сохранены локально и не обозначены успешными. WebKit проверяется с эмуляцией iPhone, физический телефон не проверялся; этот выпуск не заявляет исправление общей производительности или OOM.

Дополнительная проверка отдельных моделей выявила различие идентификаторов наземного и морского «Зенита». Финальная редакция содержит три точных перехода к этим моделям; статьи и источники не менялись. Дополнительные проверки повторяют открытие всех21карточки и двустороннюю навигацию по «Зениту-3SLБ», «Зениту-3SL» и «Союзу-5» на обоих движках.
