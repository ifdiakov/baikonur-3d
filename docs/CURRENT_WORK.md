## Как работать дальше
1. Точечно прочитать нужные исходники и связанный раздел истории. Не перечитывать весь PROJECT_CONTEXT и старую переписку.
2. Внести один согласованный набор правок. Подготовительные генераторы запускаются до фиксации версии, а не изменяют main из CI.
3. Запустить быстрый контроль синтаксиса/импортов и профильный тест текущей функции; посмотреть контрольный ракурс. Основной музей нельзя заменять облегчённой сценой.
4. Перед публикацией проверить актуальный main, сохранить чужие изменения. После Pages сверить публичные файлы и профильный сценарий. Короткий общий smoke не заменяет проверку изменённой функции.
