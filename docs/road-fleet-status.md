## Сделано без исходников

- `src/road-fleet.js`: отдельный от каталога загрузчик, общий шаблон геометрии/текстур, индивидуальные материалы и оси колёс, четыре огня, масштаб колёс и наклон по дорожному полотну, повтор загрузки после ошибки. Окраска должна быть подготовлена в экспортируемом GLB, манифест подтверждает вариант `black` / `original` / `grey`.
- `src/road-vehicles.js`: обычные автомобили заменены циклическим распределением трёх типов; прежние позиции Sprinter сохранены. `road-fleet` — отдельная фоновая задача, промотируется при фокусе на машине. До готовности GLB автомобиль скрыт, условный кузов не показывается. География/маршруты/скорости не изменены.
- `src/ground-traffic.js`: доступен `loadRoadFleet()` для проверки/повторной загрузки; версии импортов обновлены в цепочке до `index.html`.
- `tests/road-fleet.mjs`: проверки повторной загрузки, конкурирующих запросов, независимого затухания, вращения колёс с масштабом, позы на склоне, отсутствия условного кузова и исключения из каталога. **Это проверки на тестовой геометрии, не на скачанных автомобилях.**

## Блокировка и оставшаяся работа

Файлы трёх моделей пока **не получены**. Официальный Download API требует авторизацию (HTTP 401), кнопка скачивания открывает вход в Sketchfab. В защищённом окне входа выбран Google; последующая проверка состояния вкладки заблокирована автоматической проверкой безопасности с требованием явного разрешения пользователя. Не обходить блокировку чтением сессии/куки/скрытых URL. Папка Google Drive `_Техника 3D` проверена до этой блокировки: указанных трёх файлов там нет.

**Не сливать эту ветку в main и не публиковать до получения файлов и визуальной проверки.** В `assets/models/road-fleet/` пока нет GLB/манифестов; при преждевременной публикации новая часть трафика будет скрыта из-за отсутствующих файлов.

После получения исходников:

1. Облегчить геометрию и текстуры, перекрасить только кузов, оставить узнаваемые силуэты, окна, оптику и колёса. Зафиксировать исходные лицензии/авторов и изменение цвета в `credits.html`; в каталог экспонатов ничего не добавлять.
2. Нормировать каждую модель: метры, +Y вверх, +Z вперёд, низ колёс y=0. Разделить четыре колеса, сохранить исходный запасной диск неподвижным. Проверить ориентацию и реальные габариты.
3. Положить для каждого ID `model.glb` и `manifest.json` в `assets/models/road-fleet/<id>/`. Манифест: `version` = `road-fleet-20261108-v1`, `id`, `unit: metre`, `forward: +Z`, `paint`, `halfWidth`, `bounds.size`, `asset.bytes/triangles`, четыре `wheels` с `name/center/radius`, четыре `lights` с `position/kind` (`head`/`tail`). Добавить данные происхождения/лицензии. В GLB не должно быть внешних ресурсов.
4. Проверить фактические GLB, силуэты, цвета, колёса и посадку на АД, движение обеих полос, день/ночь, мобильный вид, загрузку/повтор после ошибки. Существующий `tests/road-vehicles-browser.mjs` содержит исторические ожидания схемы дорог — не считать его полным актуальным OSM-тестом.
5. Синхронизировать с актуальной main, опубликовать GitHub + Pages и подтвердить релиз по CI и публичным хешам файлов.

Локальные проверки подготовки пройдены: `road-fleet.mjs` (тестовые активы), `road-vehicles-geometry.mjs`, `sprinter-source.mjs`, `menu-catalog-contract.mjs`, `git diff --check`. Реальные автомобили и визуальный результат не проверены — исходники отсутствуют.
