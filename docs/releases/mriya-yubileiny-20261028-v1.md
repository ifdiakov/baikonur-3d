# Мрия и Буран на Юбилейном

На перроне площадки 251 установлен оптимизированный самолёт из пользовательского
архива MriyaBuran.7z. Модель заменяет процедурный экспонат после успешной загрузки.

- 1,43 МБ для близкого просмотра и 0,59 МБ для общего плана; автоматическое LOD-переключение.
- Общий масштаб аэродрома сохранён; добавлены 32 колеса и стойки выпущенного шасси.
- Погрузочная рампа, стоянка, освещение и существующие размеры полос сохранены.
- Прямая ссылка: https://ifdiakov.github.io/baikonur-3d/?view=mriya
- При ошибке загрузки остаётся процедурная модель; импортированные поверхности доступны для выбора площадки.

Окраска предварительная: исходный OBJ не содержит привязок цветовых текстур.

Проверки: геометрия аэродромов; браузерная загрузка обоих GLB; переключение уровней
детализации; контакт колёс с перроном; сохранение модели при недоступности GLB;
дневной и вечерний вид; отсутствие ошибок JavaScript и шейдеров.
