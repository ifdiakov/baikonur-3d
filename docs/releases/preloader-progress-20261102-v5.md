# Байконур — статусы по прогрессу загрузки

Скорость открытия первого экрана имеет приоритет. Все 20 прописных статусов теперь связаны с девятью реальными этапами подготовки макета. Отдельный таймер по 2,2 секунды на фразу удалён из рабочего прелоадера.

При переходе загрузки к следующему этапу промежуточные статусы выводятся по порядку в доступных кадрах браузера. Текст появляется сразу, без анимации из нулевой прозрачности. Поэтому ускорение загрузки ускоряет смену фраз, а остановившийся этап не заставляет счётчик показывать будущий прогресс. Пауза останавливает декоративную иллюстрацию; реальные обновления загрузки продолжаются.

Настоящий первый рендер по-прежнему выполняется до объявления готовности. После него полоса сразу достигает 9/9, а финальный статус «ЗАЖИГАНИЕ/КИСЛОРОД!» завершает последовательность. При обычной работе прелоадер закрывается после оставшихся кадров и короткого затухания до 100 мс. Прежний предел выхода 460 мс сохранён как верхняя граница; отдельного ожидания полного сценария нет. При скрытой вкладке, сокращённом движении или ручной паузе сохранён немедленный переход к готовому музею. Если браузер не успевает отрисовать отдельный кадр для каждой фразы, скорость открытия остаётся приоритетом.

Поэтапная загрузка сохранена: тяжёлые модели, знания и другие дополнительные материалы запускаются после раскрытия первого интерактивного вида. Проверки сетевых сроков, повторной загрузки, настоящего первого кадра, общего снятия inert и ограниченной очереди дополнительных задач остаются обязательными.

Отдельная страница `preloader.html` показывает короткий демонстрационный цикл. Её демонстрационный таймер не участвует в загрузке настоящего музея. Сетка, размеры шрифтов, слоган и точные 20 строк сохранены.
