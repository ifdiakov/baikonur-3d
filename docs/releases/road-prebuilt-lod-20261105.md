# Предварительно рассчитанная дорожная схема и LOD — 2026-11-05

Новая сборка `scripts/build-road-lod.mjs` получает актуальные OSM GeoJSON
и записывает `data/osm/road-lod-prebuilt-v1.json`. В ней содержатся
две географически привязанные визуальные сетки (overview и medium) для
автодорог и ЖД. Douglas–Peucker удаляет только промежуточные точки
**визуального слоя**; реальные графы, мосты, габариты, атрибуция и
источники данных OSM не меняются.

На сайте `src/road-lod.js` превращает компактный набор линий в объединённые
треугольные полосы. По нормализованной высоте карты:

* H > 900 — дальняя схема транспортной сети;
* 350 < H <= 900 — схема среднего разрешения;
* H <= 350 — оригинальная полноценная 3D-дорожная сеть, разметка, подъезды,
  мосты и ЖД без модификации.

Компиляция выполняется в CI, а не в браузере посетителя. На первой версии
карта по-прежнему строит исходный граф и 3D-сеть до `startup.ready`;
LOD экономит GPU-отрисовку в обзорных ракурсах, но сам по себе ещё **не**
устраняет критические 20 секунд построения полной сети.
Следующий этап — предварительно собранная точная детальная геометрия
и её гидратация без тяжёлых расчётов в основном потоке.
