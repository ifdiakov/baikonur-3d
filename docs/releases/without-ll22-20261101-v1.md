# Удаление МиГ-25 ЛЛ22

По запросу владельца удалена схематическая модель МиГ-25 ЛЛ22: из каталога 3D-моделей, карточки Юбилейного, загрузчика и сцены посадки «Бурана». Геометрия и отдельная анимация ЛЛ22 больше не создаются.

Исходная модель МиГ-25 (борт 31) остаётся в коллекции. Посадка «Бурана», её исторические источники, шасси и парашюты сохранены.
