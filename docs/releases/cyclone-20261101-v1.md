# «Циклон» и площадка №90

Добавлены «Циклон-2» на двух исторических стартовых позициях №90 и отдельный «Циклон-3» с «Коронас-Фотоном» в коллекции моделей. Исходные детали для 3D-печати собраны, окрашены и сжаты для браузера. Ступени можно разнести для осмотра.

Старт реконструирован по фотографиям: низкая пусковая установка, транспортёр-установщик, мачты, прожекторы, служебные здания и подъездные пути. В карточке доступны ракурсы и скрытие ракет. Позиции связаны с существующей сетью, огни включаются вместе с вечерним режимом.

Размеры сооружений и скрытый газоотвод интерпретированы по фото. «Циклон-3» обозначен как экспонат Плесецка. Источники и пределы реконструкции: `docs/cyclone-reference.md`.
