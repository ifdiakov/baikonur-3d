# Оптимизация первого экрана музея — 2026-11-03

Первая итерация сокращения критического пути, без изменения 3D-геометрии и функций:

- Из четырёх изображений прелоадера только первое остаётся `src`, остальные три откладываются через `data-src`. Модуль `museum-preloader.js` уже реализует `ensureImageReady` с отложенным декодированием.
- Полные исторические главы (`src/complex-history-content.js`) и редакторская панель теперь загружаются только по нажатию на главу. В меню остаётся компактный набор названий глав.
- Код детальной PBR-земли (`src/terrain-game-detail.js`) теперь динамически импортируется внутри уже существующей очереди `startup.defer` после первого кадра.
- Для версионированных УКСС и ТУА отключено принудительное HTTP `no-cache`; обычный `default` позволяет повторно использовать неизменившиеся файлы по локальной политике сервера. URL и версии остаются теми же.
- Тест защищает эти решения от случайного возвращения к прежней загрузке. Следующие изменения — профилирование затрат на геоданные и построение сетей.

Ожидаемая экономия: три изображения галереи не инициируют запрос до фактического использования; десятки КБ кода и главы истории исключены из первичного графа модулей. Точную экономию времени определяет браузерное измерение на одинаковых сетевых условиях.
