# МиГ-25 по новым референсам

Двухместная РУ №32 заменена одноместным МиГ-25 №46 по 17 новым изображениям. Перестроены фюзеляж, нос, кабина, крыло и оперение; добавлены подвесной бак, деталировка обшивки и открытых сопел. Самолёт открывается с убранным шасси, которое можно выпустить для осмотра.

Новая модель доступна в меню «Ракеты и техника», карточке Юбилейного и по прямой ссылке `workshop/model.html?model=mig25`. Старые ссылки продолжают работать. Добавлен ракурс снизу. ЛЛ22 в исторической посадке «Бурана» остаётся отдельным экспонатом.

Проверки: геометрия и открытые каналы, текстуры и память, семь ракурсов, управление шасси, мобильный просмотр, вход из меню/карточки, старые ссылки, общий каталог из 17 моделей. Сохранены изменения дороги у площадки №45 и карточек объектов.
