# Площадка 31/6: предоставленная 3D-модель

Исходник: `baikonur_cosmodrome_site_31_pad_6.glb`, Google Drive `1yGX-pSrVWfFp9XvA8XoLRommtOYt0dKN`.

Автор: **Soviet Model Magic**, [оригинал](https://sketchfab.com/3d-models/baikonur-cosmodrome-site-31-pad-6-1b505f3a9cfd4df7a4746d1c66b53671), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Эти данные взяты из метаданных предоставленного GLB, сохранены в GLB/манифесте и доступны в карточке площадки.

Сохранены геометрия стартового стола, четыре опоры, сомкнутые фермы обслуживания, галереи под стартом, две молниезащитные и три осветительные башни. Удалены семь объектов подложки, дальних зданий и рамп исходной диорамы: на их месте используется существующий спутниковый контур газоотвода, рельеф и подключённые дороги/рельсы музея. Башни подняты основаниями к общему уровню земли; их размеры не изменены. Исходная геометрия оставшихся объектов не упрощалась.

Один метр модели соответствует одному метру локальной площадки; внешний масштаб музея — 0,14. Ось входящего железнодорожного пути — +Z, выход газоотвода — −Z. Привязка и высоты остаются музейной реконструкцией, не инженерным обмером. Глубокие части исходного фундамента скрываются под сохранённым дном газоотвода.

109 604 треугольника; материалы сведены в палитру без изменения цветов, геометрия сжата Meshopt. Файл около 2,1 МБ вместо 9,5 МБ, два вызова отрисовки основной модели. «Союз» загружается отдельно из общего существующего файла.

Смена визуальной модели сохраняет корень площадки, вырез грунта, ракету и точки присоединения транспорта. Во время загрузки и при ошибке видна резервная модель; повтор загрузки доступен в карточке. Новая геометрия автоматически включается в выбор объектов мышью.

Проверки: `node tests/site31-source-model.mjs`, `node tests/site31-geometry.mjs`; браузерный прогон `tests/site31-source-browser.mjs` проверяет сбой/повтор загрузки, пять ракурсов, переключение ракеты, авторство и мобильные кнопки. Публикация сверяется по байтам изменённых файлов.
