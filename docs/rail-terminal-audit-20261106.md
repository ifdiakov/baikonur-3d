# Сверка тупиков ЖД Байконура с площадками — 06.11.2026

**Исходные данные.** Архивная геометрия OpenStreetMap: data/osm/railways.geojson (543 объектов; 513 действующих и 30 исторических). Пункты станций: data/osm/rail-points.geojson. Геопривязанные площадки: data/catalog.json и data/osm/catalog-matches.json. Схема железнодорожного хозяйства: src/rail-scheme.js, пользовательский архив «Схема подъездного пути космодрома Байконур».

**Способ проверки.** Тупиком считается конец реального OSM пути с одной действующей связью по исходному node ID, без соединения по случайному визуальному пересечению. Каждому концу вычисляется ближайшая железнодорожная площадка и станция в музейной геопривязке. Назначение подтверждается только принадлежностью к зоне железнодорожного приёма, станционным горловинам, рабочим рельсовым воротам/сокетам моделей или защищённым путям из схемы.

**Что остаётся.** Все 20 маршрутов по схеме станций, реальные пути к Гагаринскому, площадкам 31, 45, 81, 92, 110, 112/112А, 200, 250, 251 и другим площадкам с железнодорожной приёмкой; отдельные узлы, подтверждённые по 3D-воротам, станционные пути «Космотранс», «Юбилейная», «Горная», «Братская» и перечисленные в RAIL_SCHEME_YARDS парки. Сохраняется внешний железнодорожный ход и источники со значением usage=main/branch.

**Что удаляется только из отображения.** Короткие неименные тупиковые ответвления без точки назначения, вне зон станций и железнодорожных площадок. Максимальная удаляемая тупиковая ветка: 85 мировых единиц. Реальные координаты OSM, маршруты графа и исторические (abandoned) линии не удаляются из источников: они нужны для реконструкций.

**Автоматическая проверка.** src/rail-terminal-cleanup.js и tests/rail-terminal-cleanup.mjs; фактический результат доступен в transport.stats().branchSimplification.rail (назначения концов, удалённые тупики, список площадок, защищённые связи). Любое изменение рельсовых ворот, позиций экспонатов или схемы требует повторной проверки.

**Ограничение.** Отсутствие железнодорожного назначения в доступной музейной базе не доказывает, что путь исторически не использовался. Это очистка схемы в интерактивном музее, не эксплуатационный план железных дорог.
