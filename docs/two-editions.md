# Мастерская и облегчённый музей

`museum.html` — отдельный публичный просмотрщик. Первый кадр: каталог и подготовленный рельеф с дорогами, запечёнными в изображения поверхности. Исходный OSM и редакторы не загружаются. Модели площадок, описания и более чёткие текстуры — при приближении и выборе; кеш ограничен. В неподвижной сцене отрисовка останавливается. Тяжёлые реконструкции и полноценная живая сцена доступны по действию в iframe, который удаляется при закрытии.

`workshop.html` — полная сцена и редактор: высотомер, координаты, метки дорог, высота/позиция/поворот/масштаб объектов, дорожные узлы и связанное перемещение совпадающих узлов перекрёстка, рисование/удаление дорог. Черновики сохраняются локально, доступны отмена/повтор и экспорт/импорт.

`index.html` сохранён как прежняя совместимая версия, чтобы не ломать отправленные ссылки и исторические проверки. Адрес лёгкой версии в этом релизе — `museum.html`.

## Публикация
Скачанный из мастерской `workshop-state.json` загрузить через свою учётную запись GitHub в `data/workshop-state.json`. Браузер не хранит токены GitHub. URL мастерской на GitHub Pages **не защищён авторизацией**: его можно открыть, но серверная публикация требует прав GitHub. Для закрытой мастерской нужен серверный шлюз авторизации.

Сборка: `python3 scripts/prepare-two-editions.py`, `node scripts/build-public-app.mjs`, локальный HTTP-сервер, `node scripts/build-public-data.mjs`. Проверки: `node tests/workshop-state.mjs`, `node tests/two-editions-browser.mjs`. Публиковать собранные данные только после успешных проверок и просмотра снимков; повторять измерения на GitHub Pages. Изображения и GLB получены из авторской сцены; обязательная атрибуция остаётся в `credits.html`.

## Три отчёта после каждого обновления
Независимые AI-агенты в текущей среде не запускались. Отчёт разделён по трём направлениям:
1. 3D-графика и подготовка моделей: что изменилось, что стало легче, ограничения.
2. Интерфейс: возможности владельца и посетителя, сохранение правок, улучшения.
3. Тестирование: реально проверенные сценарии, условия сети и устройств, ошибки и непроверенные случаи.

Мобильный размер окна — не замер на телефоне. Один прогон — не медиана нескольких. Зелёный workflow не доказывает отсутствие всех визуальных дефектов. Запекание старых перекрёстков не исправляет автоматически их исходную геометрию. Перемещение объекта не перепроектирует автоматически все соседние дороги.
