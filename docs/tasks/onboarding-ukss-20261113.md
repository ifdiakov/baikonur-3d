# Обучение: полёт к УКСС вместо Гагаринского · 13.11.2026

Указание владельца: в обучающем режиме вместо Гагаринского камера летит на УКСС. Первоначальное чтение сообщения как жалобы на неправильный полёт отменено; реализуется именно замена цели обучения на УКСС.

В трёх входных страницах callback focusUkss открывает pad-250 через openMenuSite, не числовой индекс. Подсказка указывает УКСС «Энергия». Начальный трёхсекундный пролёт флангов,29-секундная общая длительность, облёт выбранного объекта, исходный обзор в конце и кнопка Пропустить сохранены. На границе этапов предыдущая интерполяция завершается до начала следующего движения, чтобы редкий кадр не оставлял центр облёта между площадками. Ручной осмотр Гагаринского старта не менялся.

Локально пройдены существующие сценарии обучения, новые проверки точной конечной позиции и пропущенного кадра, синтаксис/импорты266 модулей и3 страниц. Локальная загрузка HTTP-страницы заблокирована средой браузера; полноценная проверка выполняется в существующем GitHub Actions процессе, без обхода ограничения. Не считать опубликованным до публичного passed:true и сверки файлов. Браузерный профиль проверяет настоящий контроллер и сцену, изменяет только тестовое время; это не замер FPS и не физический телефон.
