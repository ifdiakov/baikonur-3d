# Удаление девяти условных групп · 12.11.2026

Запрос: убрать Восточно-центральный сектор, Западно-центральный сектор, Северную городскую инфраструктуру, Северный протяжённый комплекс, Северо-западный сектор — группы А/Б, Юго-восточный сектор, Южную техническую и Южную транспортную группы.

Реализация: src/map-visible-sites.js содержит точный список девяти ID. До создания моделей выбираются только оставшиеся записи. Удалённые группы не получают мешей, кликабельных объектов, фонарей, плашек, пунктов меню или записей редактора. Прямые ссылки не находят удалённый объект. Фильтр используется в index/museum/workshop. Исходные архивные сведения и массив географических/дорожных привязок сохранены: изменение списка объектов не отменяет дорожные кеши и не перестраивает сеть. Вариативность оставшихся условных зданий использует их прежний индекс, а не новый уплотнённый порядок.

Проверки: tests/map-group-removal-source.mjs (ровно девять удалённых ID, сохранность всех остальных записей/координат/порядка/входа транспортного кеша); tests/map-group-removal-browser-checks.mjs подключён к существующему короткому браузерному сценарию. Проверяются отсутствие в сцене/плашках/меню/редакторе, отказ старых ссылок, сохранность реальных площадок и выбор82/83/175 после изменения индексов. Main не генерирует и не записывает изменения из CI. Подготовка HTML разрешена только в изолированной ветке fix/remove-map-groups-20261112; браузеры проверяют конкретный SHA после подготовки.

Статус на создании записи: кандидат; публичная готовность ещё не подтверждена. Не считать непрофильные старые задачи исправленными.
