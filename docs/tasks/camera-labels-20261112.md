# Крайний: область камеры и уровни подписей · 12.11.2026

Запрос: вернуть область осмотра аэропорта Крайний; номера площадок с H300, подробные карточки с H130.

Причина ограничения: museumCameraBounds включал только FLANK_OUTLINE. Крайний за этим контуром; constrainFreeCamera возвращал точку вращения к краю флангов. Теперь к прежним границам добавляется полный мировой bounding box существующего аэродрома с120 единицами запаса. Это постоянная область свободного обзора, не только исключение для открытой карточки. Сами фланги/их заливка не изменяются. Ограничения высоты, конечная граница камеры и её центра, клиренс рельефа сохранены.

Единая политика src/map-view-policy.js использует H=camera.y/SCENE_SCALE (высотомер). H>300: номера/подробные карточки скрыты;130<H<=300: компактные номера;H<=130: подробные карточки. Два уровня взаимоисключающие, пороги включительные. Ручное открытие объекта и существующие исключения карточек реконструкций сохранены. Настройка одинакова в index/museum/workshop. Меню, фонари, туман, транспорт, модели и дорожные кеши не меняются.

Проверки:21 исходный сценарий; браузер проверяет301/300/299/131/130/129, пять ракурсов Крайнего после ограничителя, четыре края аэропорта при выбранной другой площадке, сохранение внешних границ и высотомера. Опциональный профиль выполняется в существующем процессе проверки, без нового издателя. Статус: кандидат, не считать опубликованным до чтения публичного отчёта и просмотра снимков.
