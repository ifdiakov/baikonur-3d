# Поделиться: копирование ссылки · 11.11.2026

Текущий запрос: кнопка в карточке площадки, техники или события сразу копирует ссылку на этот объект и показывает пользователю подтверждение. Меню социальных приложений НЕ открывать.

Реализовано на актуальной основной версии после ремонта delivery. Повторно использована незавершённая ветка карточек, основанная на том же приложении db8b3cc; более новые изменения CI и документации сохранены. Общие данные, модели, дороги, туман, свет и транспорт не меняются.

src/card-share.js: Clipboard API вызывается прямо из нажатия; успех показывается только после завершения копирования. При отказе — реальное резервное копирование через временное выделение, затем честное сообщение и выбираемая ссылка для ручного копирования. Вызова navigator.share нет. Сообщение успеха: «Ссылка скопирована в буфер обмена», 3,5 секунды, aria-live. Нет покадровых обновлений, внешних share-сервисов или аналитики.

Публичные адреса конкретных площадок, МИК/ТУА, МЗК/СДИ, техники и событий; из админки и iframe ведут в музей без черновика. Входящая ссылка открывает нужную карточку; события не запускаются автоматически. Добавлены кнопки также в статьи энциклопедии. Значок по прежнему референсу владельца — собственный SVG.

11 исходных проверок пройдены локально. Профильная приёмка в существующем verify-encyclopedia-media.yml: desktop/mobile/workshop параллельно, реальный буфер обмена с чтением результата, подтверждение, переход по скопированному URL, модельный iframe, динамическая панель события, резервное копирование и запрет обоих способов. На main дополнительно сверяются девять опубликованных файлов. Завершение только по успешным публичным отчётам; до них готовность на сайте не заявляется. Остальные незавершённые задачи сохраняются.
